About the project

A practical research tool for evidence-grounded LLM verification.

Problem

Large language models can generate answers that sound convincing but are not supported by the source material. This project checks generated claims against retrieved evidence from a research paper.

Approach

The application retrieves relevant passages from an uploaded PDF, asks Gemini to answer only from that evidence, extracts factual claims, and verifies each claim using Natural Language Inference.

Technologies

Python, FastAPI, pypdf, Sentence Transformers, FAISS, RoBERTa-large-MNLI, Gemini and a lightweight browser dashboard.

How to interpret the result

SUPPORTED means the retrieved evidence entails the claim. CONTRADICTED means evidence supports the opposite. UNKNOWN means the available evidence was not sufficient for a confident verification. Unknown claims contribute half-weight to the project-defined risk score and an all-unknown result is labelled UNCERTAIN.
